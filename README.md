# 👾 Devleoper Portfolio

Personal portfolio site — who I am, what I've built, and how to reach me.

## Features

- **AboutMe** — pixel-art hero with a walking-cat animation that runs across the screen
- **Knowledge** — ID-card-styled bento grid; hover (or tap) any tech to see a one-line context
- **Experience** — i18n-driven timeline of roles
- **Projects** — live data: fetches my public repos from the GitHub API, filters by the `portfolio` topic, and renders the top 4 with descriptions, per-repo language icons, and links. The card representing this repo gets a "★ YOU ARE HERE" badge.
- **Contact** — Formspree-backed form with inline validation, success / error states, and social links (GitHub, LinkedIn, Instagram)
- Dark / light mode
- Bilingual (EN / ES) with browser-language detection
- Open Graph / Twitter card image generated by a script

## Stack

- [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS v4](https://tailwindcss.com/)
- [i18next](https://www.i18next.com/) + `react-i18next` (EN / ES)
- [react-icons](https://react-icons.github.io/react-icons/) for brand icons
- [Formspree](https://formspree.io/) free tier for contact form submissions

## Running locally

Built with [Bun](https://bun.sh/), but npm works too.

```bash
# install dependencies
bun install         # or npm install

# start dev server (http://localhost:5173)
bun dev             # or npm run dev

# build for production (regenerates the OG image, then runs Vite)
bun run build       # or npm run build

# preview the production build
bun preview         # or npm run preview

# regenerate only the OG / Twitter card preview image
bun run og          # or npm run og
```

## Project structure

```
src/
├── components/                 # Shared UI used across sections
│   ├── Navbar.jsx
│   └── TechIcon.jsx            # Portal-based tooltip icon used by Knowledge + Projects
├── context/
│   └── AnimationContext.jsx    # Tracks which sections have entered view (one-shot fade-in)
├── lib/
│   └── techIcons.js            # Single registry of tech badges (icon, color, GitHub language map)
├── hooks/
│   └── useGithubRepos.js       # Fetches + caches repos, attaches language icons
├── i18n/
│   ├── index.js                # i18next setup
│   └── locales/                # en.json, es.json
└── sections/
    ├── AboutMe/                # Hero + walking cat
    ├── Knowledge/              # ID card with skill bento
    ├── Experience.jsx          # Timeline
    ├── Projects/               # GitHub-driven project cards
    └── Contact.jsx             # Form + social links
public/
├── animations/                 # Cat sprite frames
├── og-banner.png               # OG / Twitter card image, regenerated on every build
└── ...                         # Other static assets
scripts/
└── generate-og.mjs             # Renders public/og-banner.png from current design tokens
```
